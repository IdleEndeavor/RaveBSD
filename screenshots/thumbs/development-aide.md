# screenshots/thumbs/ : README thumbnails

Small JPEG copies of the screenshots one folder up, shown in the README's grid (desktop two per row, phone four per row). Each `<img>` here is wrapped in a link to the full-size PNG in `screenshots/`.

Each has the same base name as its PNG with a `.jpg` extension. Desktop thumbnails are 760px wide and phone ones 360px wide, and none carry metadata.
